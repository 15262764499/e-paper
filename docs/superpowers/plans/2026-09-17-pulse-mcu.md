# Pulse MCU Implementation Plan

**Goal:** Implement the already agreed desktop Pulse v1 protocol on USART1 and build application + bootloader on this Windows computer.
**Architecture:** Bounded interrupt RX ring, main-context protocol parsing and ACKs, pure testable parser/effect, SysTick animation and 3-second expiry. NFC remains a temporary override; local mode selection cancels computer control. STOP/expiry select OFF. No flashing in this task.
**Tech Stack:** STM32 HAL, C, native GCC tests, Arm GNU GCC, MinGW Make, PowerShell.
